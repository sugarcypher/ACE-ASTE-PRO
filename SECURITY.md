# Security Policy

## Supported Versions
| Version | Supported |
|----------|------------|
| 1.x | ✅ |
| < 1.0 | ❌ |


If you discover a security vulnerability, You can report security issues privately at https://github.com/sugarcypher/ace-aste-pro/security/advisories/new
.

We will:
- Acknowledge receipt within 48 hours.
- Provide an update within 7 days on the status of the issue.
- Credit you (if desired) in the release notes once the fix is published.
Please do not disclose the vulnerability publicly until we have released a fix.
