How to use this page

  1. Make sure the extension is loaded at chrome://extensions.
  2. Open the toolbar popup. Under Page scanner, enable Scan every page for hostile invisible characters.
  3. Reload this page. You should see:
    • A red badge with a number on the toolbar icon (the count of hostile chars).
    • A red banner top-right: "⚠ N hostile invisible characters on this page".
    • Click the banner → contaminated text below gets red outlines.
  4. To test quarantine on copy: select any of the contaminated text below and copy it (Cmd/Ctrl+C). A green toast should appear: "🧼 Sanitized N hostile chars from copy". Paste into a plain editor — it should be clean.
  5. To test quarantine on paste: paste contaminated text into the textbox at the bottom. Same green toast — and what lands is already clean.
  6. To test the bypass key: hold Shift while copying. No toast = bypass worked, contamination passes through to the clipboard.
